Which AI field is this paper? Classifying arXiv abstracts

Give a model the title and abstract of a research paper and ask which of seven AI fields it belongs to. Ten models, from word counts to fine-tuned transformers, compete on 14,000 real papers.

Data arXiv API · Frameworks scikit-learn, Keras, PyTorch + Hugging Face Transformers · Final model SciBERT + TF-IDF ensemble · Notebook NLP_ArxivPaperClassification.ipynb

About this report

arXiv, the open preprint server, receives thousands of new papers every week. Each one is filed under a primary category: is a paper on retrieval-augmented language models Information Retrieval, Computation and Language or Artificial Intelligence? Authors choose, moderators check, and conference systems use the same kind of label to route submissions to reviewers. This project asks how well a model can make that call from the abstract alone.

It is the text counterpart of my image-classification project (cats vs dogs and 37 breeds): the same workflow on a different kind of data. Data quality and exploration come first, then a model selection across six families of models, an honest test, and a decision on how the model should be used.

All numbers come from one run of the accompanying notebook on a free Colab T4 GPU. Hover over the charts for exact values. New to NLP? Open the NLP primer first; otherwise start with the data.

Background · optional

NLP primer

The ideas the report relies on. Each topic is folded; open the ones you need.

How does a computer read text?Tokens, vocabulary, bag of words

A model needs numbers. The first step is tokenisation: splitting text into units such as words ("robot", "grasping") or word pieces ("grasp", "##ing"). The set of all known tokens is the vocabulary.

The simplest representation is a bag of words: one column per vocabulary word, one row per document, each cell counting how often the word appears. Word order is lost, but for "which field is this?" the words alone already carry most of the signal.

TF-IDFWeighting words by how informative they are

Raw counts over-weight words like "model" that appear everywhere. TF-IDF multiplies the term frequency in a document by the inverse document frequency, idf = log(N / df), where df is the number of documents containing the word. Rare, specific words ("manipulation", "posterior") get large weights; common ones shrink towards zero.

  • n-grams: also count word pairs ("language model", "sample complexity"), which carry meaning single words miss.
  • Sublinear tf: use 1 + log(tf), so a word repeated ten times is not ten times as important.
  • The result is a very wide, very sparse matrix: here up to 200,000 columns, almost all zero for any one abstract.
Linear classifiers for textNaive Bayes, logistic regression, linear SVM
  • Naive Bayes learns how likely each word is in each field and multiplies the evidence, assuming words are independent. Very fast, a classic text baseline. The complement variant used here is more stable when classes differ.
  • Logistic regression learns one weight per word and field; a softmax turns the seven weighted sums into probabilities. C controls regularisation: smaller C means smaller weights and less overfitting.
  • Linear SVM draws the boundary with the largest margin between fields (hinge loss). Often the most accurate linear model, but it gives scores, not calibrated probabilities.
Word embeddings and neural networksEmbedding layer, TextCNN, BiLSTM

An embedding maps each word to a dense vector (here 128 numbers) that is learned during training, so that words used in similar contexts get similar vectors. Neural networks then read the sequence of vectors:

  • TextCNN slides 128 filters over windows of five words and keeps the strongest response of each filter, which acts as a learned phrase detector.
  • BiLSTM reads the abstract left-to-right and right-to-left with a memory cell whose gates decide what to keep and what to forget.

Trained from scratch, both must learn the language from about 10,000 abstracts, which is very little.

Transformers, attention and BERTPretrained language models and fine-tuning

Self-attention lets every token look at every other token and decide which ones matter for its meaning: softmax(Q·Kᵀ / √d)·V. Stacking attention layers gives a transformer.

BERT is a transformer pretrained on huge amounts of text by hiding words and predicting them (masked language modelling). It arrives already knowing a lot about language. Fine-tuning adds a small classification layer and trains all weights for a few epochs at a tiny learning rate (3e-5 here).

  • DistilBERT: a smaller BERT (6 layers, 66 M parameters) distilled from the full model; general English.
  • SciBERT: BERT pretrained on 1.14 million scientific papers, with its own scientific vocabulary.
  • MiniLM sentence embeddings: a small transformer trained to map a whole text to one 384-number vector, so that texts about similar things land close together. Used frozen here, as a feature extractor for logistic regression.
Measuring a multi-class classifierPrecision, recall, F1, macro-F1, top-2 accuracy
  • Precision for a field: of the papers the model put there, the share that belong there. Recall: of the papers that belong there, the share the model found.
  • F1 = 2 · precision · recall / (precision + recall), the balance of the two.
  • Macro-F1: the plain average of the seven F1 scores, so every field counts equally. The main metric of this report.
  • Top-2 accuracy: the right field is one of the model's two highest-probability answers. It matters when the model suggests rather than decides.
  • Confusion matrix: rows are true fields, columns predicted fields; everything off the diagonal is a mistake.

03 · Exploratory analysis

Distinct vocabularies, overlapping fields

The classes are balanced (1,995 to 2,000 papers each) and abstracts have similar length (medians 179–199 words), so neither size nor length gives a field away. Two things matter more: which other fields a paper is listed in, and which words it uses.

04 · Split

Stratified 70 / 15 / 15

Training 9,789 · validation 2,098 · test 2,098 papers, each with the same share of every field. Every model is trained on the training set and compared on the validation set; the test set is used once, for the final model only. The TF-IDF vocabulary and the neural tokenisers are fitted on training papers only, so nothing about validation or test leaks in.

Selection rule: highest validation macro-F1. TF-IDF + Logistic Regression sets a strong bar (0.739 in 22 s), above the best network trained from scratch (TextCNN, 0.722) and the frozen MiniLM embeddings (0.724). SciBERT beats DistilBERT (0.756 vs 0.734): pretraining on scientific papers pays off. Averaging SciBERT with TF-IDF logistic regression adds 0.6 points at almost no cost, so Ensemble: SciBERT + TF-IDF LR is the final model.

06 · Tuning

The classical baseline is already close to its best

A fair comparison needs a tuned baseline. A 12-trial grid varies the TF-IDF features (single words vs words + pairs; minimum document frequency 2 or 5) and the regularisation C of logistic regression (1, 4, 16).

The best setting (word pairs, C = 1, min_df 2) reaches 0.743, +0.4 points over the setting used in model selection. With word pairs every C scores within 0.002 of each other; with single words, the weakest regularisation (C = 16) costs 1.6 points against the best C. Tuning does not change the ranking: fine-tuned SciBERT stays ahead.

08 · Decision policy

Suggest two fields; send the unsure to an editor

A 78%-accurate classifier should not file papers on its own. Three rules make it useful anyway:

  • Suggest, don't decide. Show authors the top two fields: the right one is among them 91.2% of the time.
  • Automate only confident cases. Below a confidence threshold, the paper goes to a human moderator.
  • Treat cross-listed answers as partial credit. A suggestion that matches a secondary category is useful, not wrong.

Lessons

  • TF-IDF with logistic regression is the baseline to beat: 0.739 in seconds, interpretable, and better than neural networks trained from scratch on 10,000 texts.
  • Pretraining is what makes neural models win, and domain matters: SciBERT beats DistilBERT.
  • A cheap ensemble of a transformer and a word-count model adds a little more, because they look at different things.
  • The ceiling is set by the labels: many papers belong to two fields, so top-2 accuracy and cross-listing tell more than accuracy alone.

Limitations and next steps

  • Time confound. Fields cover windows from 16 to 232 days; sampling all fields from the same weeks would make the comparison cleaner.
  • Multi-label. Predicting every category a paper is listed in (multi-label classification) matches the real task better than one label.
  • One run, one split. Transformer scores vary between runs; several seeds or cross-validation would tighten the comparison.
  • More text. Only title and abstract are used; the introduction or references would add signal.
