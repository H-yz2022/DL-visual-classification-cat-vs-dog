Deep learning projects

Teaching models to see and to read

Two end-to-end classification projects with one workflow: photos of pets, and abstracts of research papers. Each starts with data quality and exploration and ends with a decision policy: when should the model answer on its own, and when should a person check?

About this section

Both projects follow the order of a machine-learning report. Is the data clean? What does it look like? Which simple model is the baseline to beat? Which model wins on validation data, with which settings? How good is it on data it has never seen, and where does it fail? Every number comes from a notebook that runs end to end on a free Colab GPU, and every chart in the reports shows exact values on hover.

Start with either project below, or use the menu at the top to switch at any time.

Computer vision

Cats vs dogs, then 37 breeds

A convolutional network learns to tell cats from dogs in 23,262 adoption-site photos, then a second part names the breed among 37. Covers image EDA, duplicate detection, transfer learning, Grad-CAM and an "is this even a pet?" gate.

What carries over

  • Baseline first. A simple model tells you how hard the task is, and sometimes it is hard to beat.
  • Pretrained beats from scratch when data is limited: ImageNet networks for photos, BERT-style models for text.
  • The test set is touched once. Models and settings are chosen on validation data only.
  • Accuracy is not a policy. Both projects end with a rule for when the model should not decide alone.
